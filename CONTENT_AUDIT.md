## Decisions and disagreements

| Item | Evidence and treatment |
| --- | --- |
| Fast Run | `2282463` versus `2288463` after `1-999` in published guides. CATCHME maps to the former, but keypad arithmetic alone is not console proof. Phone variant withheld; agreed controller sequence shown. |
| Drunk Mode | `547867` versus `547861` after `1-999`. LIQUOR maps to the former. Same conservative treatment: phone withheld, controller shown. |
| Rapid GT | GTA Base / GamesRadar start with two R2 presses; iGrandTheftAuto / GTA BOOM start with one. Controller variant withheld; agreed `1-999-727-4348` shown. |
| PCJ-600 / Sanchez | GamesRadar reverses these vehicle entries. GTA Base, iGrandTheftAuto and GTA BOOM agree on PCJ `1-999-762-538` and Sanchez `1-999-633-7623`, with different matching controller sequences. |
| Trashmaster | GTA BOOM's phone listing drops a digit. GTA Base and iGrandTheftAuto support `1-999-8727-433` (formatting differs, digits agree); matches TRASHED. |
| Super Jump | iGrandTheftAuto's controller line conflicts. Use the GTA Base / GTA BOOM / GamesRadar sequence. Test Xbox evidence comes from GTA BOOM. |
| Explosive ammo Xbox test fixture | iGrandTheftAuto ends its Xbox row in the invalid label L1. The separate GTA BOOM Xbox row is used for this fixture instead. |
| Weapons | Describe a weapon loadout plus ammo; do not promise every weapon or unlimited ammo. |
| Wanted level | Exactly one star per activation, rather than a universal “remove police” promise. |
| Skyfall | No usable parachute during the cheat. Includes context restrictions; not recommended as guaranteed early-game travel. |
| Three special spawns | Dodo requires Sea Plane; Duke O'Death requires Duel; Kraken requires Wildlife Photography Challenge. Prominent unlock badge; excluded from Quick picks. |
| Black cellphone | The number is agreed; sources disagree on additional explosion behavior. Only the phone appearance effect is described. |
| Count | 34 gameplay cheats plus Director Mode and Black Cellphone: “36 cheats & extras.” No invented money, tank or jet spawn code. |
| SR9 Strawberry | Source street labels conflict (Innocence Boulevard / Elgin Avenue). District and original pin retained; conflict disclosed. |
| PR4 northwest hills | Source text and original labels differ (Tongva Drive / Banham Canyon / Richman Glen). Broad area and actual screenshot retained; all names searchable. |
| Store count | PowerPyx explicitly lists 19 eligible Story Mode hold-up stores. Checking all 19 is not required for its single hold-up completion activity. No Online award claim. |
